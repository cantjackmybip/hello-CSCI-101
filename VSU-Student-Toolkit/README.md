Step 1: Access the GitHub Repository (5 minutes)
1. Log into your GitHub account at github.com.
2. Navigate to the repository URL provided by your instructor.
3. Review the files in the repository.
The project contains a main Python program and a folder for student contributions:
VSU-Student-Toolkit/
│
├── student_toolkit.py
├── README.md
│
└── student_tools/
    └── example_calculator.py


Step 2: Create Your Branch (5 minutes)
1. On the repository's main page, locate the branch selector, which initially displays main.
2. Click the selector and enter a new branch name.
3. Use the format student-yourusername, replacing yourusername with your GitHub username.
4. Select the option to create the branch from main.
5. Verify that your new branch is selected.




Do not upload your work directly to the main branch. Each student must work in their own branch.
Step 3: Download the Python Files (5 minutes)
1. With your branch selected, click the green Code button.
2. Select Download ZIP.
3. Extract the ZIP file onto your computer.
4. Open the extracted folder using your preferred text editor.
You now have a local copy of the Python program.

Step 4: Create Your Python Function (20 minutes)
Inside the student_tools folder, create a new Python file using your name or GitHub username.

For example:

jsmith_grade_calculator.py

Each student will add one simple utility to the class program.

Your Python file must contain a TOOL_NAME variable and a function named run().

For example:
TOOL_NAME = "Grade Calculator"

def run():    
   print("Welcome to the Grade Calculator!")    
   score = float(input("Enter your score: "))    
   if score >= 90:        
       print("Your grade is A")    
    elif score >= 80:        
        print("Your grade is B")    
    elif score >= 70:        
        print("Your grade is C")    
    elif score >= 60:        
        print("Your grade is D")    
    else:        
        print("Your grade is F")


Students may choose from the following functions as an idea

The function must use at least one of the following Python concepts: user input, conditional statements, loops, or calculations.
Step 5: Test Your Function (10 minutes)
1. Save your Python file inside the student_tools folder.
2. Run student_toolkit.py using Python.
3. Verify that your new function appears in the menu.
4. Select your function and verify that it works correctly.
5. Take a screenshot showing your function working.
You should not modify the main student_toolkit.py file.
Step 6: Upload Your Python File to GitHub (10 minutes)
1. Return to the GitHub repository in your browser.
2. Verify that your personal branch is selected.
3. Open the student_tools folder.
4. Click Add file → Upload files.
5. Drag your completed Python file into the upload area or choose it from your computer.
6. Enter a commit message such as Added grade calculator function.
7. Commit the changes to your personal branch.
Upload only your new Python file. Do not upload the entire downloaded project or overwrite files belonging to other students.

After committing, verify that your file appears inside student_tools on your branch.
